# 样本数据约定

产品文案和样本内容集中在此目录；类型契约属于 `src/types/`，交互状态属于业务功能。

- `sidebar.ts`：四个领域及 32 个项目会话条目。
- `conversations.ts`：320 条项目会话消息与本地固定回复；默认不出题。
- `learning.ts`：解释、代码和明确请求练习时的题目。
- `maps.ts`、`workspace.ts`：已积累概念、关系和实验状态。
- `product.ts`：项目、两个独立会话、项目归属建议、四份教程、16 章内容和有用户原话来源的证据。

- `project-suggestions.ts`：用于前端流程的固定项目建议；真实 Agent 尚未接入。

ID 必须稳定且可追溯。教程内容引用原助手消息；理解证据引用用户消息，不能将助手讲解或阅读视为用户已经理解。未知状态用 `null`。数值仅为未校准样本，不是模型评估结果。

初始化种子不得由页面直接修改。运行时状态使用独立副本；引用保存当时文本、版本和来源，章节后续变化不覆盖历史引用。后台推断和生成尚未接入，不能将这些固定内容当作算法验证数据。
