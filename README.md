# Swartz

English · [简体中文](README.zh-CN.md)

A public-benefit project for understanding and sharing knowledge: turning questions and exploration into a book of your own, and letting what one person learns become a path someone else can follow.

**[Read our conviction →](https://lilhammerfun.github.io/swartz-site/en/)**

## Run locally

Requires Node.js 24+, Rust stable, and the [Tauri platform dependencies](https://tauri.app/start/prerequisites/).

```sh
git clone https://github.com/lilhammerfun/swartz.git
cd swartz
npm ci
npm run desktop
```

For a browser preview, run `npm run dev`. Connect your own model service in Settings to use AI conversations.
