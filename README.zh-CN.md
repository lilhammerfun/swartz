# Swartz

[English](README.md) · 简体中文

一个关于理解与分享知识的公益项目：把疑问与探索慢慢变成一本自己的书。

> **WIP：** Swartz 正在开发中，尚未发布稳定版本。

**[阅读我们的信念 →](https://lilhammerfun.github.io/swartz/)**

## 本地运行

需要 Node.js 24+、Rust stable 和 [Tauri 平台依赖](https://tauri.app/start/prerequisites/)。

```sh
git clone https://github.com/lilhammerfun/swartz.git
cd swartz
pnpm install --frozen-lockfile
pnpm desktop
```

浏览器预览使用 `pnpm dev`。AI 交流需在 Settings 中连接自己的模型服务。
